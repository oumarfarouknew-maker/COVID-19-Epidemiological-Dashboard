# COVID-19 Global Data Analysis

## Project Overview
Analysis of global COVID-19 trends using WHO data.

## Objectives
- Explore COVID-19 patterns worldwide
- Calculate epidemiological indicators
- Build interactive dashboard

## Dataset
Source: World Health Organization (WHO)

Variables:
- Date_reported
- Country
- WHO_region
- New_cases
- Cumulative_cases
- New_deaths
- Cumulative_deaths

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Power BI
- GitHub

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Epidemiological Indicators
4. Power BI Dashboard
5. Report Writing

## Key Findings
- Global cases exceeded 100 million
- CFR approximately 1.2%
- Regional differences observed
